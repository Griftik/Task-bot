# Jarvis — единая точка входа

Это **не** Telegram-бот с задачками. Это общая память и напарник по реализации задумок:
единое место, где видно состояние всех проектов и задач, чтобы не держать это в голове
и двигаться **каждый день, а не наплывами**.

## Как это работает

1. **Захват.** Ты надиктовываешь голосовые с телефона (Claude Code / claude.ai).
   Сырые надиктовки падают в `inbox.md`.
2. **Разбор.** Я разбираю inbox → раскладываю по проектам и типам, ставлю статусы,
   дедлайны и следующий шаг.
3. **Память.** Всё состояние живёт в этом репозитории. Я перечитываю его в начале
   каждой сессии — так «эфемерный чат» становится напарником, который помнит.
4. **Утро.** Расписание (Routine) будит меня каждое утро → я собираю визуальную сводку
   «где что стоит» и присылаю тебе.
5. **Дело.** По каждой задаче оцениваю, могу ли сделать сам. Что могу — беру (с твоего
   «ок»): ресёрч → в заметку, пост → черновик, код → в репозиторий проекта. Что не
   могу — напоминаю и организую.
6. **Встречи.** Нужна встреча — задействую календарный агент (Google Calendar).

## Точка входа (решение)

- **Дом — Claude Code (веб/телефон), как сейчас.** Сюда наговариваешь голосовые; здесь
  живёт репозиторий-мозг, отсюда я делаю ресёрч/код/дашборд и ставлю утреннее расписание.
- **claude.ai-приложение** — лёгкая альтернатива для «просто поговорить» голосом с телефона.
- **Telegram-бот — на паузе.** Ядром он не нужен; позже можно вернуть как быстрый
  «диктофон» в `inbox.md`.

## Структура

- `inbox.md` — сырые надиктовки до разбора
- `projects/` — по файлу на проект: тип, статус, зачем, следующий шаг, открытые вопросы, лог

## Легенда статусов

🔵 активен · ⏸ пауза · 🧊 идея/бэклог · ✅ готово

> ❓ в файлах — то, что мы ещё не проговорили. Заполняем вместе, голосом.

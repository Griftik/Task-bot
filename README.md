# Task-bot 🧠

Телеграм-бот на Claude, который работает как **внешняя память для задач**.
Пишешь ему всё, что нужно сделать, в свободной форме — а он:

- 🤖 **сам делает** то, что можно закрыть без тебя (найти, написать, посчитать,
  сравнить, перевести, набросать код) и присылает готовый результат;
- 📌 **запоминает и напоминает** про то, что за тобой (позвонить, сходить,
  решить, оплатить);
- 🎯 **помогает сфокусироваться** — по команде `/focus` подсказывает, с чего
  начать прямо сейчас, чтобы не распыляться и не забывать.

Цель — разгрузить голову: не держать список дел в памяти, часть делегировать
Claude, а про остальное вовремя получать напоминания.

---

## Как это работает

```
твоё сообщение ──▶ Claude разбирает на задачи ──┬─▶ 🤖 AI-задача  → делаю сам → результат
   (в любой                                      │
    форме)                                        └─▶ 📌 твоя задача → напоминание + /focus
```

1. Ты пишешь боту одно сообщение — хоть одну задачу, хоть список вперемешку.
2. Claude превращает его в отдельные структурированные задачи и для каждой
   решает: это может сделать ассистент **или** это должен сделать человек.
3. AI-задачи запускаются в фоне сразу; результат приходит отдельным сообщением.
4. Личные задачи сохраняются; если указано время — ставится напоминание.

> ⚠️ Бот не совершает действий в реальном мире (не отправляет письма, не платит,
> не заходит в твои аккаунты). AI-задачи — это «умная работа с текстом»:
> исследование, черновики, ответы, код. Всё готовое ты просматриваешь сам.

## Быстрый старт

### 1. Создай бота в Telegram

Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи **токен**.

### 2. Получи ключ Anthropic

На [console.anthropic.com](https://console.anthropic.com/settings/keys) создай
API-ключ.

### 3. Настрой и запусти

```bash
git clone <этот-репозиторий>
cd Task-bot

python -m venv .venv && source .venv/bin/activate   # опционально
pip install -r requirements.txt

cp .env.example .env      # и впиши токены (см. ниже)
python -m bot.main
```

Открой своего бота в Telegram и нажми `/start`.

### 4. Сделай бота приватным (рекомендуется)

Пока `TASKBOT_ALLOWED_CHAT_IDS` пуст, бот отвечает **всем**, кто его найдёт (и
тратит твои кредиты Anthropic). Напиши боту `/whoami`, узнай свой ID и впиши его
в `.env`:

```env
TASKBOT_ALLOWED_CHAT_IDS=123456789
```

## Настройки (`.env`)

| Переменная                  | Обязательна | По умолчанию     | Что делает |
|-----------------------------|:-----------:|------------------|------------|
| `TELEGRAM_BOT_TOKEN`        | да          | —                | Токен из @BotFather |
| `ANTHROPIC_API_KEY`         | да          | —                | Ключ Anthropic API |
| `ANTHROPIC_MODEL`           | нет         | `claude-opus-5`  | Модель. Дешевле: `claude-sonnet-5`, `claude-haiku-4-5` |
| `TASKBOT_ALLOWED_CHAT_IDS`  | нет         | (пусто = всем)   | Кому можно пользоваться (ID через запятую) |
| `TASKBOT_TIMEZONE`          | нет         | `UTC`            | Часовой пояс для «завтра в 9» и напоминаний, напр. `Europe/Moscow` |
| `TASKBOT_DB_PATH`           | нет         | `taskbot.db`     | Путь к базе SQLite |
| `TASKBOT_DAILY_BRIEF`       | нет         | (выкл.)          | Время утренней сводки `ЧЧ:ММ`, напр. `09:00` |

## Команды

| Команда        | Что делает |
|----------------|------------|
| (просто текст) | Добавить задачи — бот сам разберёт и распределит |
| `/tasks`       | Открытые задачи с кнопками «Готово / Ещё раз / Убрать» |
| `/today`       | Что на сегодня и просроченное |
| `/focus`       | Выбрать одну задачу, с которой начать |
| `/result <id>` | Показать результат AI-задачи |
| `/done <id>`   | Отметить выполненной |
| `/cancel <id>` | Убрать задачу |
| `/whoami`      | Узнать свой chat id |
| `/help`        | Справка |

Под задачами и напоминаниями есть кнопки — можно закрывать и откладывать в один
тап, без команд.

## Архитектура

```
bot/
├── main.py        точка входа: сборка Application, регистрация хендлеров
├── config.py      чтение и валидация настроек из окружения / .env
├── models.py      Task и перечисления (категория, статус, приоритет)
├── db.py          хранилище на SQLite
├── claude.py      обёртка над Anthropic API: разбор, выполнение, фокус
├── prompts.py     системные промпты и JSON-схема для извлечения задач
├── keyboards.py   инлайн-кнопки
├── scheduler.py   напоминания и утренняя сводка (JobQueue)
└── handlers.py    команды, сообщения, кнопки
```

- **Telegram:** [python-telegram-bot](https://python-telegram-bot.org) 21
  (async), напоминания — на встроенном `JobQueue`.
- **Claude:** официальный SDK `anthropic`. Разбор задач — через structured
  outputs; выполнение — с веб-поиском (server-side `web_search`).
- **Хранилище:** SQLite, одна таблица `tasks`.
